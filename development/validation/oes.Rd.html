oesR Documentation

Internal Calculation Helper for Effect-Size-Based Y-Axis Ranges

Description

Internal, unexported calculation helper used by optimal_graph. Users should call optimal_graph(detail = TRUE) and inspect the returned oes component for numerical limits and metadata. Compute an Optimal Effect Size (OES) y-axis recommendation from a factorial design, with optional calculation details. The implementation uses constants from a single-factor, two-level empirical calibration; broader factorial and repeated-measures applications are computational generalizations.

Usage

oes(
  data, DV, within = NULL, between = NULL, pooled = TRUE,
  error_bar = c("ci95", "ci95_dif", "ci95_corr", "ci95_dif_corr", "se", "sd"),
  range_type = c("dp", "quantile", "data"), id = NULL,
  effect = c("d", "g"), measurement_range = NULL,
  verbose = TRUE, detail = FALSE
)

Arguments

data

A data frame of raw responses, or one row per design cell. For summary input, DV identifies the cell mean; optional n, sd, and se columns describe cell variability. Raw data are required to estimate the maximum effect in this version.

DV

Response column, supplied as a bare name or character string.

within

Within-subject factor names, as bare names or a character vector. Use c(...) for multiple factors. Default NULL.

between

Between-subject factor names, with the same syntax as within. At least one factor must be supplied.

pooled

Whether error bars use pooled rather than cell-specific variability. The OES expansion always uses a single pooled variability estimate, regardless of this argument.

error_bar

Error-bar method. "ci95" uses ordinary 95 percent confidence intervals; "ci95_dif" multiplies their half-widths by \sqrt{2}. "ci95_corr" uses Cousineau–Morey correlation-adjusted base intervals without \sqrt{2}; "ci95_dif_corr" also applies the \sqrt{2} multiplier. "se" and "sd" use one standard error and one standard deviation, respectively.

range_type

Base range before expansion: "dp" uses the outer error-bar endpoints; "quantile" uses the 2nd and 98th response percentiles; "data" uses the measurement or observed response range. The latter two choices are exploratory.

id

Participant ID column, as a bare name or character string. Required for paired within-subject effects and correlation-adjusted CIs.

effect

"d" uses Cohen's d for between-subject contrasts and paired Cohen's dz for within-subject contrasts. "g" applies Hedges' correction to between-subject contrasts only; within-subject contrasts still use dz. Recommendations using g or paired dz have not been empirically validated; see the evidence and limitations section.

measurement_range

Optional numeric vector c(min, max) giving a finite, strictly increasing theoretical response range. Otherwise the observed range is used. This supplies the "data" base range and the fallback range. It does not clamp OES recommendations.

verbose

Whether to emit optional methodological and fallback warnings. Errors are not suppressed.

detail

If FALSE, return limits only. If TRUE, return calculation details in an object of class oes_result.

Details

The effect search compares levels of each factor while conditioning on the other factors. Within-subject comparisons match observations by participant ID. Specify the experimental design explicitly; grouping variables alone do not identify repeated measurements.

Between-subject contrasts use rstatix::cohens_d(var.equal = FALSE). Their standardized mean difference divides by \sqrt{(s_1^2 + s_2^2)/2}, even when group sample sizes differ; it does not use an n-weighted two-group SD. Hedges' g uses the correction implemented by rstatix. This contrast denominator is separate from the degrees-of-freedom-weighted pooled cell SD used for ER variability.

For maximum absolute effect X \geq 0.20, the expansion on each side is ER = s_p/(X + a), where s_p is pooled within-cell SD for ordinary error bars or pooled transformed SD for Cousineau–Morey intervals. The parameter a uses the inherited calibration constants described below: 5.723 for X \geq 0.8, 1.575 for 0.5 \leq X < 0.8, and 0.254 for 0.2 \leq X < 0.5. These values are retained in this version and may change in later versions as further evidence becomes available. If X is unavailable or smaller than 0.20, the measurement or observed range is returned directly. The default range_type = "dp" and effect = "d" retain the calibration's method choices; selecting them does not establish empirical validity for every supported design. The output phrase “calibrated OES expansion” refers to use of the inherited formula and constants, not to empirical validation of all supported designs or effect estimators.

Correlation-adjusted intervals require raw data, valid participant IDs, at least one within-subject factor, at least two repeated-measures conditions per between-subject stratum, complete within-participant condition profiles, and at least two participants per stratum. Duplicate participant-condition responses are averaged first. Their t critical value uses n - 1 degrees of freedom for both pooling settings. Confidence-interval options follow the distinctions in Cousineau (2017). Difference adjustment multiplies half-widths by \sqrt{2} (Equation 3). Repeated-measures base intervals use Cousineau's (2005) normalization and Morey's (2008) bias correction. The separate "ci95_corr" option returns these base intervals without \sqrt{2} and is not the 2017 article's combined comparative construction. "ci95_dif_corr" adds \sqrt{2}, combining the adjustments described in Equation 5b. "se" and "sd" use one standard error or standard deviation. These sources support CI construction; the OES expansion rule and calibration constants come from the effect-size manuscript.

Value

With detail = FALSE, a one-row data frame with lower and upper. With detail = TRUE, a list of class oes_result containing range (that data frame), res (cell summaries and error bars), dp (maximum absolute effect), effect_info, effect_table (conditional comparisons), pooled_sd, ER, sd_info, error_bar_info, range_info, L, U, and args. On fallback, ER is NA and L/U are the final fallback bounds; otherwise they are the base bounds before expansion. The range_info$calibrated flag is TRUE exactly when range_type = "dp", including on fallback. It identifies the original base-range choice, not empirical validation of a generalized design, effect estimator, or recommendation.

Evidence and limitations

Visualizing Standardized Effect Sizes Using the Framework of Graph Perception and Data Visualization (Shuo Zang and Denis Cousineau, 2026, unpublished manuscript) studied single-factor, two-level comparisons across different populations and sample sizes, focusing on Cohen's d. The package's support for broader independent, repeated-measures, and mixed factorial designs is a computational generalization of that work, not empirical validation of those generalized y-axis recommendations.

Recommendations using Hedges' g, paired Cohen's dz, multi-factor maximum-effect selection, or the generalized ER rule beyond the studied comparisons remain unvalidated extensions. Alternative base ranges "quantile" and "data" are also exploratory. Software tests verify implemented calculations and behavior; they do not validate perceptual outcomes for these extensions.

A separate methods paper is planned to explain the package's derivation from the effect-size study. The planned methods paper is not yet published, and no bibliographic citation for it is included here.
