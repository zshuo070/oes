oes-packageR Documentation

oes: Optimal Effect-Size-Based Y-Axis Ranges

Description

Compute effect-size-informed y-axis recommendations and display them with mean/error-bar plots or existing ggplot objects. Calibration constants come from single-factor, two-level comparisons. The implementation supports broader between-subject, within-subject, and mixed factorial designs as computational generalizations.

Details

optimal_graph is the package's sole exported function. Use it for graphical and text output, or request detail = TRUE with graph output and inspect the returned oes component for numeric limits and calculation metadata. Calculation helpers are internal. Recommendations depend on the specified design and effect-size method; explicitly identify repeated measurements and participant IDs.

Confidence-interval options follow the distinctions in Cousineau (2017). Difference adjustment multiplies half-widths by \sqrt{2} (Equation 3). Repeated-measures base intervals use Cousineau's (2005) normalization and Morey's (2008) bias correction. The separate "ci95_corr" option returns these base intervals without \sqrt{2} and is not the 2017 article's combined comparative construction. "ci95_dif_corr" adds \sqrt{2}, combining the adjustments described in Equation 5b. "se" and "sd" use one standard error or standard deviation. These sources support CI construction; the OES expansion rule and calibration constants come from the effect-size manuscript.

Visualizing Standardized Effect Sizes Using the Framework of Graph Perception and Data Visualization (Shuo Zang and Denis Cousineau, 2026, unpublished manuscript) studied single-factor, two-level comparisons across different populations and sample sizes, focusing on Cohen's d. Broader independent, repeated-measures, and mixed factorial support does not constitute empirical validation of the generalized y-axis recommendations. Hedges' g, paired dz, multi-factor maximum-effect selection, and generalized ER use beyond the studied comparisons are unvalidated extensions. Alternative base ranges are exploratory.

The parameter a is taken directly from the effect-size study: 5.723 for X \geq 0.8, 1.575 for 0.5 \leq X < 0.8, and 0.254 for 0.2 \leq X < 0.5. These values may change in later versions as further evidence becomes available. See optimal_graph for the exact implemented expansion, pooling, and fallback rules.

A separate methods paper is planned to explain the package's derivation from the effect-size study. It is not yet published; the package does not supply a citation to that planned paper.

Version 1.0.0 is the first public package version, based on the V1.8 development implementation. The code is available under the MIT license. Run citation("oes") for the software citation.

Public data resources

The effect-size manuscript is associated with Shuo Zang and Denis Cousineau's 2025 OSF resource, Visualizing Standardized Effect Sizes Using the Framework of Graph Perception and Data Visualization, licensed under CC BY 4.0: \Sexpr[results=rd]{tools:::Rd_expr_doi("10.17605/OSF.IO/DRCTA")}. This DOI identifies the OSF resource, not a published-paper or software DOI.

The supplied Study4_long.csv example data come from Shuo Zang and Denis Cousineau's 2025 OSF project, “When Error Bars Fail to Correct Misleading Charts: Judgments of Lower y-axis Truncation across Layouts and Audiences”, under CC BY 4.0. The project and source-file links are \Sexpr[results=rd]{tools:::Rd_expr_doi("10.17605/OSF.IO/DTYBF")} and https://osf.io/dtybf/files/ebsh5. This is the error-bar project, not the effect-size calibration dataset. The package's self-contained examples and tests do not download these resources or require their files.
