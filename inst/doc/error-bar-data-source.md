# Error-bar Study 4B: Study4_long.csv source and license

The CSV accompanies the manually run study example, not the mandatory
package tests. The CSV is included only in the project ZIP; `development/`
is excluded from the installable source archive. This provenance document
is included in the installed package as well.

- Creators: Shuo Zang and Denis Cousineau.
- Resource: *When Error Bars Fail to Correct Misleading Charts: Judgments
  of Lower y-axis Truncation across Layouts and Audiences*.
- Host: Open Science Framework (OSF); DOI metadata publication year: 2025.
- Resource DOI: <https://doi.org/10.17605/OSF.IO/DTYBF>.
- File page: <https://osf.io/dtybf/files/ebsh5>.
- Direct download: <https://osf.io/download/ebsh5/>.
- OSF path: `/Studies/Study4B/Study4_long.csv`; file version 1.
- License: Creative Commons Attribution 4.0 International (CC BY 4.0),
  <https://creativecommons.org/licenses/by/4.0/>.
- Retrieved: 2026-10-08. The distributed CSV is unmodified.
- SHA256: `77d0afb17d980a8370cb3f62c222848a5b773d7c10663977523925554c08d454`.

The file contains 240 rows, 30 participant IDs, and complete profiles for
four EB levels crossed with two distortion levels. The `format` column
has one level in this file and is not treated as an additional design factor
in the manual example.

The example converts columns to factors in memory and identifies EB and
distortion as within-subject factors. It does not modify the CSV. Cite the
resource and retain attribution and the CC BY license link when reusing
or redistributing these data. This data license is separate from the MIT
license for package code. No endorsement by the resource creators is implied.

These data come from the error-bar study. They are a package-usage example,
not the effect-size study's calibration data or empirical validation of generalized OES rules.

## Related effect-size research resource

The separate effect-size manuscript is *Visualizing Standardized Effect Sizes
Using the Framework of Graph Perception and Data Visualization*, by Shuo
Zang and Denis Cousineau. Its OSF resource is
<https://doi.org/10.17605/OSF.IO/DRCTA>. This is an OSF research-resource DOI;
it is not the software DOI or a published-journal-article DOI.
The effect-size resource lists `Studies/Study4/Study4_raw.xlsx`, a different
file from the error-bar `Studies/Study4B/Study4_long.csv` used here.
